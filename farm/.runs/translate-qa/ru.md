# Начало работы с PipeForge

PipeForge превращает записанную сессию в детерминированный конвейер. Установите пакет, затем
запустите компилятор на вашей трассе. Среда выполнения исполняет конвейер и записывает вердикт
для каждого запуска.

## Быстрые шаги
1. Установка: `npm install -g pipeforge`
2. Скомпилируйте вашу трассу в конвейер.
3. Запустите конвейер; проверьте вердикт в логах.

Если вердикт сообщает об ошибке, шаг починки читает трассу и исправляет сбойную стадию.
