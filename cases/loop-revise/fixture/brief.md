# Product brief — Reharness

Reharness is a reasoning compiler. It turns a plain-language request into a runnable,
FSM-based AI workflow, so a task you'd otherwise hand to an agent every single time gets
compiled once and then runs cheaply on every later invocation.

- Audience: engineers who automate repeated LLM workflows.
- Tone: precise, technical, a little bold. No fluff, no buzzwords.
- Product name to use verbatim: **Reharness**
